# IDA System — Sub-repositorio Driver / Periféricos

## 📌 Visión General
Módulo de servicios e integración con periféricos de hardware en caja y consulta clínica (impresoras térmicas de tickets/vales, básculas digitales, lectores de código de barras y visores).

## 🛠️ Stack Tecnológico
- **Lenguaje**: Go / Python / Node.js perfiles de controlador.
- **Protocolos**: POS/ESC Thermal Printing, Serial/USB HID Barcode Scanners.
